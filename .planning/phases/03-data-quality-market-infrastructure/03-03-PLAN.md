  <action>
    1. In `src/config/settings.py`:
       - Ensure `polling_interval_sec: int` defaults to 15 (or matches settings configuration).
    2. Implement `src/ingestion/kite_quote_poller.py`:
       - `get_active_holding_symbols() -> dict[str, int]`:
         - Queries `user_holdings` for instruments with `(quantity + t1_quantity) > 0`.
         - Returns mapping `{ f"{exchange}:{tradingsymbol}": instrument_token }`.
       - `poll_kite_quotes() -> dict[str, Any]`:
         - If no active holdings, logs debug message and returns `{"status": "no_holdings", "updated": 0}`.
         - Calls `kite.quote(symbols)` using `get_authenticated_kite()`.
         - Handles `TokenException` -> logs error, calls `invalidate_token()`, returns `{"status": "token_expired"}`.
         - Handles `(NetworkException, GeneralException)` -> logs warning, returns `{"status": "network_error"}`.
         - Atomically upserts each instrument into `live_prices`:
           `last_price`, `open_price`, `high_price`, `low_price`, `close_price`, `volume`, `change_absolute`, `change_percent`, `source = 'kite'`, `is_stale = FALSE`, `last_updated = NOW()`.
           Uses `ON CONFLICT (instrument_token) DO UPDATE` with `IS DISTINCT FROM` filter.
         - Archives each record to `price_history` (`source = 'kite'`, `recorded_at = NOW()`).
         - Marks missing quotes as `is_stale = TRUE`.
         - Returns summary dict with `{"status": "ok", "updated": updated_count, "total": len(symbols)}`.
       - `run_kite_polling_daemon()`:
         - Infinite loop: checks `is_market_open()`.
         - If open: runs `poll_kite_quotes()`, sleeps `polling_interval_sec`.
         - If closed: sleeps `seconds_until_market_open()` in chunks, logging next open time.
    3. Update `src/ingestion/yahoo_poller.py`:
       - Add module-level `warnings.warn("yahoo_poller is deprecated for live pricing; use src.ingestion.kite_quote_poller instead.", DeprecationWarning, stacklevel=2)`.
       - Log prominent deprecation warning if run as a script.
  </action>
