  <action>
    1. In `src/execution/validators/slippage_check.py`:
       - Define `DEFAULT_STALENESS_THRESHOLD_SEC = 60`.
       - Implement `_refresh_on_demand_price(order: RebalanceOrder) -> Decimal | None`:
         - Formats `symbol = f"{order.exchange}:{order.tradingsymbol}"`.
         - Calls `kite = get_authenticated_kite(); ltp_dict = kite.ltp([symbol])`.
         - If valid `last_price` > 0 returned:
           - Synchronously persists to `live_prices` (`instrument_token`, `last_price`, `source = 'kite'`, `is_stale = FALSE`, `last_updated = NOW()`).
           - Returns `Decimal(str(raw_price))`.
         - If call fails, times out, or returns <= 0:
           - Logs error and returns `None`.
       - Update `validate_slippage(order: RebalanceOrder) -> tuple[bool, str]`:
         - First, check if instrument is inactive:
           - Query `SELECT is_active FROM instrument_master WHERE instrument_token = :token`.
           - If `is_active is False`: return `(False, f"Instrument {order.tradingsymbol} is inactive or delisted.")`.
         - Read `slippage_bound_pct` (default 2.0%) and `price_staleness_threshold_sec` (default 60s) from `system_config`.
         - Query `last_price, is_stale, last_updated` from `live_prices`.
         - Determine if price is stale:
           - If `is_market_open()` is `True`:
             - If no row exists, `is_stale` is True, or `(now_ist() - last_updated).total_seconds() > staleness_thresh`: mark `needs_refresh = True`.
           - If `is_market_open()` is `False`:
             - If no row exists: return `(True, f"No live price outside market hours. Using estimated price ₹{order.estimated_price}.")`.
             - Else: use existing price (not stale outside market hours).
         - If `needs_refresh`:
           - Call `_refresh_on_demand_price(order)`.
           - If `None`: **FAIL CLOSED** -> return `(False, f"Price is stale (>{staleness_thresh}s) or missing, and on-demand broker refresh failed for {order.tradingsymbol}.")`.
         - If `live_price is None` or `live_price <= 0`: return `(False, f"Live price for {order.tradingsymbol} is zero or unavailable.")`.
         - Compute `slippage_pct = abs(((live_price - order.estimated_price) / order.estimated_price) * 100)`.
         - If `slippage_pct > slippage_bound`: return `(False, f"Slippage too high: {slippage_pct:.2f}% (limit: {slippage_bound}%)...")`.
         - Return `(True, f"Slippage OK: {slippage_pct:.2f}% (limit: {slippage_bound}%)")`.
  </action>
