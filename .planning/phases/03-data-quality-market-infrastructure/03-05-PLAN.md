  <action>
    1. In `src/ingestion/kite_sync.py`:
       - Refactor `sync_holdings(user_id: str = "default") -> int`:
         - Retrieve raw holdings from `kite.holdings()`.
         - Query existing positions from `user_holdings` for `user_id`.
         - For each broker holding:
           - Calculate `new_total = quantity + t1_quantity`.
           - If not present in local database:
             - Record reconciliation log: `reason = "INITIAL_SYNC"`, `delta = new_total`.
           - If present in local database:
             - Compare `old_total = old_quantity + old_t1_quantity`.
             - If `delta == 0`:
               - If `old_t1 > 0 and new_t1 == 0 and new_quantity == old_total`:
                 - Record reconciliation log: `reason = "T1_SETTLEMENT"`, `delta = 0`.
             - If `delta != 0`:
               - Classify discrepancy via `_classify_quantity_discrepancy(session, token, delta, last_synced_at)`:
                 - Check `order_audit_trail` for filled BUY/SELL orders since `last_synced_at`. If net fills match delta, return `"TRADE_FILL"`.
                 - Check `corporate_actions` for active split or bonus in the last 14 days. If matched, return `"CORPORATE_ACTION_SPLIT"` or `"CORPORATE_ACTION_BONUS"`.
                 - If unexplained, return `"DISCREPANCY"`.
               - If `reason == "DISCREPANCY"`:
                 - Log high-severity alert: `logger.warning("UNEXPLAINED QUANTITY JUMP for {}: old={}, new={}, delta={}", tradingsymbol, old_total, new_total, delta)`.
               - Record reconciliation log with classified reason.
           - Ensure instrument exists in `instrument_master`.
           - Upsert verified position into `user_holdings` with updated timestamp.
         - For any local holding missing from broker response (and `old_total > 0`):
           - Classify reason, record reconciliation log with `new_qty = 0`, and set `quantity = 0, t1_quantity = 0` in `user_holdings`.
       - Implement `_record_reconciliation_log` helper to insert records into `holdings_reconciliation_log`.
  </action>
