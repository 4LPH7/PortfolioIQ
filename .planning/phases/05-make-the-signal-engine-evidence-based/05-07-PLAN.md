   - `record_eod_signals(user_id: str = "default") -> list[SignalSnapshotDTO]`:
     - Fetches active holdings and benchmark closing price.
     - Runs quantitative signal engine for each holding.
     - Persists snapshots in `signal_snapshots` with model version and timestamp.
   - `mature_forward_returns(user_id: str = "default") -> dict[str, int]`:
     - Identifies pending snapshots where 5, 20, or 60 trading days have elapsed.
     - Queries closing price on horizon date and benchmark closing price.
     - Computes stock return, benchmark return, and excess alpha.
     - Updates snapshot record with realized returns and sets `realized_{h}d_at`.
