<objective>
Implement the statistical indicator evaluation and Information Coefficient (IC) engine:
1. Standardize technical indicator implementations (RSI, MACD, Bollinger Bands, Linear Regression) into continuous directional factor scores bounded in `[-1.0, +1.0]`.
2. Compute Spearman rank Information Coefficient (IC) and two-tailed student-t p-values against forward returns using `scipy.stats.spearmanr`.
3. Enforce the independent statistical pruning gate: any indicator with mean out-of-sample $IC \le 0$ or $p > 0.05$ is assigned zero weight.
4. Dynamically weight valid indicators proportional to their Information Ratio ($IR = \text{mean}(IC) / \text{std}(IC)$), normalizing weights to sum to 1.0.
5. Author comprehensive unit tests in `tests/test_indicator_evaluator.py`.

Output: `src/analytics/indicator_evaluator.py` and passing test suite.
</objective>

   - Computes Spearman rank correlation and p-value via `scipy.stats.spearmanr`.

   - Calculates IC and p-value for each slice/fold.
   - Computes out-of-sample mean IC, sample standard deviation of IC, and Information Ratio ($IR = \text{mean}(IC) / \text{std}(IC)$).
   - Prunes indicators where $\text{mean}(IC) \le 0$ or $p > 0.05$, documenting the exact reason.
   - Dynamically weights unpruned indicators proportional to positive IR.
   - If all indicators are pruned, assigns all weights to 0.0 with clear explanatory status.
