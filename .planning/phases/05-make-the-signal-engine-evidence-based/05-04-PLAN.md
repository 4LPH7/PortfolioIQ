<objective>
Build the rolling walk-forward backtesting engine with dual-baseline attribution and transaction cost modeling:
1. Implement `src/analytics/walk_forward.py` to partition historical price series into rolling 252-day calibration and 63-day out-of-sample evaluation folds.
2. Ensure strict out-of-sample validation: indicator weights calibrated on fold $k$ are applied exclusively to test fold $k$.
3. Simulate strategy executions with realistic Indian equity delivery transaction costs (STT, DP charges, GST) to compute net realized alpha.
4. Benchmark strategy performance against dual baselines: Stock Buy-and-Hold (timing skill) and NIFTY 50 TRI Buy-and-Hold (market alpha).
5. Compute comprehensive out-of-sample performance metrics: CAGR, Sharpe, Sortino, Max Drawdown, Win Rate, and Profit Factor.
6. Author comprehensive tests in `tests/test_walk_forward.py`.

Output: `src/analytics/walk_forward.py` and passing test suite.
</objective>

<task id="05-04-02">
<title>Implement Strategy Execution, Dual Baseline Attribution & Hurdle Classification</title>
<action>
1. Implement `run_walk_forward_backtest(df: pd.DataFrame, benchmark_df: pd.DataFrame, tradingsymbol: str, train_window: int = 252, test_window: int = 63, step: int = 63, initial_capital: float = 100000.0, risk_free_rate: float = 0.065) -> BacktestRunDTO`:
   - Align stock `df` and `benchmark_df` on date indices (inner join / reindex).
   - Generate walk-forward folds via `generate_walk_forward_folds()`.
   - Compute standardized factor scores on full dataset using `compute_all_factors(df)`.
   - Fold-by-fold execution loop:
     - For each fold $k$:
       - In-sample calibration: slice training factors and forward returns, evaluate indicators via `evaluate_indicators()`.
       - Calibrated weights are frozen and applied strictly to out-of-sample test fold $k$.
       - Simulate out-of-sample daily trading:
         - Calculate daily composite score via `compute_composite_score(calibrated_evals, current_factors)`.
         - BUY threshold ($\ge 60.0$): if not invested, purchase maximum integer shares, deduct delivery charges via `compute_indian_delivery_charges("BUY", trade_value)`.
         - SELL threshold ($\le 40.0$): if invested, liquidate position, deduct delivery charges via `compute_indian_delivery_charges("SELL", trade_value)` (including DP charge).
         - Track daily portfolio NAV (cash + stock value) to construct contiguous out-of-sample equity curve.
         - Track roundtrip trades, wins, losses, and basis-point cost drag.
   - Dual Baseline Attribution over the exact same out-of-sample period:
     - Baseline 1 (Stock B&H): Buy stock on Day 1 of out-of-sample period and hold.
     - Baseline 2 (Benchmark B&H): Buy NIFTY 50 TRI on Day 1 of out-of-sample period and hold.
   - Compute performance metrics for Strategy and Dual Baselines:
     - Annualized CAGR: $(1 + \text{Total Return})^{\frac{252}{N}} - 1$.
     - Annualized Sharpe Ratio and Sortino Ratio using daily risk-free rate $(1 + r_f)^{\frac{1}{252}} - 1$.
     - Maximum Drawdown (peak-to-trough series).
     - Win Rate ($\frac{\text{Winning Trades}}{\text{Total Closed Trades}}$) and Profit Factor ($\frac{\sum \text{Gains}}{\sum |\text{Losses}|}$).
     - Excess CAGR vs Stock and Excess CAGR vs Benchmark.
   - Hurdle Verification (D-05, D-06):
     - `passed_hurdle`: Strategy must achieve positive excess CAGR vs Stock, positive excess CAGR vs Benchmark, Sharpe > Stock Sharpe, and positive win rate.
     - `status`: `"PROVEN_EDGE"` if passed hurdle, else `"UNPROVEN_NOISE"`.
   - Construct and return `BacktestRunDTO`.
</action>
</task>
