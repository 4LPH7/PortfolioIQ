<objective>
Build the rolling walk-forward backtesting engine with dual-baseline attribution and transaction cost modeling:
1. Implement `src/analytics/walk_forward.py` to partition historical price series into rolling 252-day calibration and 63-day out-of-sample evaluation folds.
2. Ensure strict out-of-sample validation: indicator weights calibrated on fold $k$ are applied exclusively to test fold $k$.
3. Simulate strategy executions with realistic Indian equity delivery transaction costs (STT, DP charges, GST) to compute net realized alpha.
4. Benchmark strategy performance against dual baselines: Stock Buy-and-Hold (timing skill) and NIFTY 50 TRI Buy-and-Hold (market alpha).
5. Compute comprehensive out-of-sample performance metrics: CAGR, Sharpe, Sortino, Max Drawdown, Win Rate, and Profit Factor.
6. Author comprehensive tests in `tests/test_walk_forward.py`.

Output: `src/analytics/walk_forward.py` and passing test suite.
</objective>

<task id="05-04-02">
<title>Implement Strategy Execution & Dual Baseline Attribution</title>
<action>
1. Implement out-of-sample trading strategy simulation:
   - Entry/exit thresholds: composite score $> 60.0$ for BUY/LONG, $< 40.0$ for CASH/EXIT.
   - Position sizing and transaction cost deduction: Call `compute_indian_delivery_charges()` on entry and exit to deduce net realized trade returns and basis-point drag.
   - Aggregate cumulative net equity curve over all out-of-sample test slices.
2. Implement dual-baseline calculation over identical out-of-sample test periods:
   - Baseline 1 (Stock B&H): Returns from buying stock on Day 1 of out-of-sample period and holding.
   - Baseline 2 (Benchmark B&H): Returns from buying NIFTY 50 TRI on Day 1 of out-of-sample period and holding.
3. Compute performance metrics for strategy and both baselines:
   - Annualized CAGR: $(1 + \text{Total Return})^{\frac{252}{N}} - 1$.
   - Annualized Sharpe Ratio and Sortino Ratio using Indian risk-free rate (6.5%).
   - Peak-to-trough Maximum Drawdown.
   - Win Rate: $\frac{\text{Winning Trades}}{\text{Total Closed Trades}}$.
   - Profit Factor: $\frac{\sum \text{Gross Gains}}{\sum |\text{Gross Losses}|}$.
4. Construct and return `BacktestRunDTO`.
</action>
</task>
