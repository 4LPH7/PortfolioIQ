<action>
1. Author `src/analytics/historical_cache.py`:
   - `get_or_sync_historical_bars(tradingsymbol: str, lookback_days: int = 750, force_sync: bool = False) -> pd.DataFrame`:
     - Queries `get_historical_bars()` from repository.
     - Inspects `max(bar_date)`.
     - If bars cover up to the last completed market trading day, returns cached DataFrame directly.
     - If missing or stale, downloads only delta bars from `yfinance`, converts to `HistoricalBarDTO`, saves via `upsert_historical_bars()`, and returns combined DataFrame.
   - `get_benchmark_bars(lookback_days: int = 750, force_sync: bool = False) -> pd.DataFrame`:
     - Dedicated helper retrieving cached NIFTY 50 TRI bars.
   - Robust error handling: if yfinance fails or rate limits, return cached bars with a warning rather than raising an unhandled exception.
</action>
</task>
