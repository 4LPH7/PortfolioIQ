<task name="task_1" type="execute">
Implement `src/analytics/performance.py`.
- `calculate_unitized_twr(snapshots: list[PortfolioDailySnapshotDTO]) -> dict`: Computes cumulative TWR and annualized CAGR from daily unit NAV progression.
- `calculate_xirr(cash_flows: list[tuple[date, float]], guess: float = 0.10) -> float | None`: Newton-Raphson solver with Brentq and bisection fallbacks handling irregular dates.
- `calculate_sharpe_sortino(daily_returns: np.ndarray, rf_annual: float = 0.065, min_warmup_days: int = 30) -> tuple[float | None, float | None]`: Annualized excess returns, std dev, downside semi-deviation below Rf, scaled by $\sqrt{252}$. Returns `(None, None)` if length < 30.
- `calculate_drawdown_series(dates: list[date], unit_navs: np.ndarray) -> DrawdownMetrics`: Computes max drawdown %, current drawdown %, HWM, peak date, trough date, recovery date.
- `calculate_beta_alpha(portfolio_returns: np.ndarray, benchmark_returns: np.ndarray, rf_annual: float = 0.065) -> dict`: Covariance/variance regression returning Beta, Jensen's Alpha %, $R^2$, and Tracking Error %.
- `compute_portfolio_performance_summary(...) -> PerformanceMetricsDTO`: Integrates all metrics and computes fee/tax drag attribution.
</task>
