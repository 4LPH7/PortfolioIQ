<task name="task_1" type="execute">
Implement `src/analytics/cost_calculator.py`.
- `compute_indian_delivery_charges(side: str, trade_value: Decimal, is_first_sell_of_scrip: bool = True) -> IndianTradeCost`:
  - Brokerage: ₹0.00 for delivery.
  - STT: 0.1% on buy and 0.1% on sell (rounded to nearest rupee).
  - Exchange Fee: 0.00297% (NSE).
  - SEBI Charges: 0.0001% (₹10/crore).
  - Stamp Duty: 0.015% on BUY only (rounded to nearest rupee).
  - GST: 18% on (Brokerage + Exchange Fee + SEBI Fee).
  - DP Charges: ₹15.34 (₹13 + 18% GST) on SELL only.
  - Return dataclass `IndianTradeCost` with full itemization and `total_charges`.
</task>

- `rebalancer_cash_buffer_pct: Decimal = Decimal("0.02")`
- `rebalancer_cash_buffer_floor: Decimal = Decimal("5000.00")`

<task name="task_3" type="execute">
Upgrade `src/analytics/rebalancer.py` (`generate_rebalance_orders`).
- Integrate `cost_calculator.py` into `RebalanceOrder` to attach estimated charges.
- Sort candidate drift signals by absolute drift magnitude descending.
- Enforce turnover cap: track running trade value; halt order generation once turnover exceeds `turnover_cap_pct * AUM`.
- Enforce cash buffer: available capital for buys = `cash_balance + sell_proceeds - max(cash_buffer_pct * AUM, cash_buffer_floor)`.
- Enforce minimum trade value: drop orders where `quantity * price < min_trade_value`, UNLESS `order.is_full_liquidation == True`.
- Enforce ADV cap: if holding ADV is provided, cap order quantity at `floor(0.01 * ADV)`. Record reason if scaled.
</task>
