<task name="task_1" type="execute">
Implement `src/analytics/snapshot_recorder.py`.
- `record_daily_eod_snapshot(user_id: str = "default", snapshot_date: date | None = None) -> PortfolioDailySnapshotDTO`:
  - Pulls current valuation from `compute_portfolio_valuation()`.
  - Retrieves previous snapshot; applies SOD external flows to adjust units.
  - Computes new `unit_nav = total_nav / units` and `daily_return_pct = (unit_nav / prev_unit_nav) - 1`.
  - Pulls NIFTY 50 benchmark close from `live_prices` or Kite quotes; computes `benchmark_daily_return_pct`.
  - Upserts snapshot into `portfolio_daily_snapshots`.
- `detect_and_sync_cash_margin_deltas(user_id: str = "default") -> list[PortfolioCashFlowDTO]`:
  - Inspects Kite margins `available.cash` delta vs local recorded cash balance.
  - Accounts for settled trades in `order_audit_trail`; any unexplained difference creates an `AUTO_MARGIN_SYNC` flow.
- `backfill_historical_snapshots(user_id: str = "default") -> int`:
  - Scans `order_audit_trail` for earliest trade date. If found, replays daily portfolio state and writes snapshots; if no trades exist, initializes Day-1 baseline at 100.00.
</task>
