<objective>

5. `POST /api/v1/rebalance/preview`: Dry-run rebalance manifest with trade sizing reasons, cost breakdown (STT, DP, GST), and tax estimates.

Purpose: Provide full frontend and API access to quantitative portfolio science and constrained rebalancing.

<task name="task_1" type="execute">
Add Phase 4 endpoints to `src/api/v1/blueprint.py`.
- `GET /api/v1/analytics/performance`:
  - Protected with `@require_api_key`.
  - Accepts `benchmark` (default `NIFTY 50 TRI`), `risk_free_rate` (default `0.065`), `window` (`30d`, `90d`, `1y`, `all`).
  - Calls `compute_portfolio_performance_summary()` and returns `PerformanceMetricsDTO`.
- `GET /api/v1/analytics/snapshots`:
  - Protected with `@require_api_key`.
  - Accepts `start_date`, `end_date`, `limit` (max 500, default 365).
  - Returns `list[PortfolioDailySnapshotDTO]`.
- `GET /api/v1/analytics/tax-harvesting`:
  - Protected with `@require_api_key`.
  - Calls `get_annual_tax_harvesting_summary()` and returns `TaxHarvestingSummaryDTO`.
- `GET /api/v1/portfolio/cash-flows` and `POST /api/v1/portfolio/cash-flows`:
  - Protected with `@require_api_key`.
  - GET lists flows; POST validates with `CreateCashFlowDTO` and records flow.
- `POST /api/v1/rebalance/preview`:
  - Protected with `@require_api_key`.
  - Generates dry-run rebalance manifest using `generate_rebalance_orders()`.
  - Returns proposed orders with itemized Indian delivery costs (`stt`, `dp_charges`, `gst`, `exchange_fee`) and estimated tax liabilities.
</task>
