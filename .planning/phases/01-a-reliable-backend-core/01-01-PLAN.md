<task type="auto">
  <name>Task 1: Implement schema_migrations tracking and line-ending normalized checksums in db/run_migrations.py</name>
  <files>db/run_migrations.py</files>
  <read_first>db/run_migrations.py, .planning/phases/01-a-reliable-backend-core/01-RESEARCH.md</read_first>
  <action>
    Refactor db/run_migrations.py to:
    1. Define `calculate_migration_checksum(file_path: Path) -> str`: Read UTF-8 text, replace '\r\n' with '\n', and compute hashlib.sha256 hex digest.
    2. Add `ensure_schema_migrations_table(conn)`: Execute `CREATE TABLE IF NOT EXISTS schema_migrations (version VARCHAR(255) PRIMARY KEY, checksum_sha256 VARCHAR(64) NOT NULL, executed_at TIMESTAMPTZ NOT NULL DEFAULT NOW()); CREATE INDEX IF NOT EXISTS idx_schema_migrations_executed_at ON schema_migrations (executed_at ASC);` and commit.
    3. Add `get_applied_migrations(conn) -> dict[str, str]`: Query `SELECT version, checksum_sha256 FROM schema_migrations` returning a dictionary of `{version: checksum}`.
    4. Implement `MigrationTamperedError(Exception)`: Raised when a local file's checksum doesn't match the database record for an already applied version.
    5. In `run_migrations()`:
       - Compare local sorted `*.sql` files against `applied` map.
       - If already applied and checksum matches: skip with notice.
       - If already applied and checksum differs: raise `MigrationTamperedError` and abort.
       - If unapplied: execute within a single transaction per migration (`conn.autocommit = False`), insert into `schema_migrations`, commit. On error, rollback and sys.exit(1).
    6. Add `--status` CLI option displaying a tabular view of all migrations and their applied status.
  </action>
  <verify>python db/run_migrations.py --dry-run</verify>
  <acceptance_criteria>
    - db/run_migrations.py contains calculate_migration_checksum with replace('\r\n', '\n')
    - db/run_migrations.py contains CREATE TABLE IF NOT EXISTS schema_migrations
    - db/run_migrations.py contains MigrationTamperedError
  </acceptance_criteria>
  <done>run_migrations.py supports transactional tracking, dry run, and tamper detection.</done>
