  <files>src/db/repository.py</files>
  <read_first>src/db/connection.py, .planning/phases/01-a-reliable-backend-core/01-RESEARCH.md, supabase_schema.sql</read_first>
  <action>
    Create `src/db/repository.py` wrapping database access with parameterized SQLAlchemy `text()` queries:
    1. `record_order_attempt(...) -> OrderAttemptDTO`: Inserts initial order attempt row into `order_audit_trail`.
    2. `record_validation_check(...) -> ValidationCheckDTO`: Inserts rule validation result into `order_validation_log`.
    3. `record_broker_execution(...) -> BrokerExecutionDTO`: Appends a new immutable row to `order_audit_trail` sharing the same `internal_order_id` (CRITICAL: never UPDATE order_audit_trail to avoid triggering 009 immutability error).
    4. `get_current_holdings(user_id="default", active_only=True) -> list[HoldingDTO]`: Returns user holdings filtered by active quantity.
    5. `get_app_config(key: str) -> AppConfigDTO | None`: Reads key from `system_config`.
    6. `list_app_configs() -> list[AppConfigDTO]`: Returns all `system_config` records.
    7. `update_app_config(key: str, value: str) -> None`: Updates setting in `system_config`.
  </action>
  <verify>python -c "from src.db.repository import record_order_attempt, record_validation_check, record_broker_execution, get_current_holdings; print('Repository functions loaded')"</verify>
  <acceptance_criteria>

    - SQL queries use parameterized :placeholders, never string formatting
    - Returns typed Pydantic DTO instances
  </acceptance_criteria>
  <done>Repository functions implemented and ready for service-layer integration.</done>
